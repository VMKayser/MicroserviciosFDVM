## 📌 Directrices de la Práctica

> **Atención:** Cree una carpeta de trabajo llamada `practica3-rest` y realice TODO el trabajo dentro de ella. Esa carpeta se sube al repositorio al final.  
> Los comandos se muestran precedidos por el símbolo `$`. NO escriba el símbolo `$` al copiar el comando.  
> Esta práctica encadena con las dos anteriores: la base de datos es la MongoDB que usted ya manejó en la Práctica 1, y el empaquetado final usa el Dockerfile y el docker compose de la Práctica 2. No empiece de cero lo que ya sabe hacer.  
> Nunca escriba la contraseña ni la cadena de conexión dentro del código: van en variables de entorno desde el Laboratorio 4.
